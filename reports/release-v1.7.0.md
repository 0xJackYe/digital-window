# v1.7.0 · 八处景观的六时段

数字窗户现在内置丹佛、曼哈顿、布拉格老城、京都、富士山、落基山湖、马尔代夫海岸和林间小径。每处有黎明、早晨、中午、下午、傍晚和夜晚，共 48 张 AI 生成图片。丹佛和曼哈顿采用高层视角，画面只显示室外景色。

- 夜景有独立的夜空、街灯与楼宇灯光。早晨和下午的受光方向、阴影与反射随各自的素材变化。
- 应用按当地日照时序连续混合相邻画面。可在日光设置里用六个时段按钮或时间滑块预览。细节来自生成的源图，因此阳光与月光的位置是画面近似。
- 所有景观随便携包提供，可离线播放。图片原生宽 1671–1672 像素、高 941 像素。

下载 Windows x64 ZIP，解压后运行 `数字窗户.exe`，保留整个目录。F11 切换全屏，右上角三个点打开景观和日光设置。
